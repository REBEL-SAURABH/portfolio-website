# 🌐 Web Development Internship Project

## 📌 Overview

This project was developed as part of my Web Development Internship at ApexPlanet Software Pvt. Ltd.

The project includes a responsive portfolio website, JavaScript interactive components, API integration, and an Expense Tracker CRUD application.

---

## 🚀 Features

### ✅ Task 1 – Responsive Portfolio Website

- Home Page
- About Page
- Services Page
- Portfolio Page
- Blog Page
- Contact Page
- Responsive Design
- Image Gallery
- Testimonials
- Google Maps Integration
- CSS Animations

---

### ✅ Task 2 – JavaScript Interactive Components

- Dark Mode Toggle
- Hamburger Menu
- Back To Top Button
- Image Slider
- Modal Popup
- FAQ Accordion
- Form Validation
- Animated Counter
- Tabs
- Tooltips
- Scroll Progress Bar

---

### ✅ Task 3 – API Integration

#### Quote Generator App

- Random Quotes
- Copy Quote Feature
- Dynamic Content Loading
- Error Handling

---

### ✅ Task 4 – Expense Tracker CRUD App

- Add Expense
- Edit Expense
- Delete Expense
- Search Expense
- Budget Alert
- Expense Categories
- Pie Chart Analytics
- Local Storage Data Persistence
